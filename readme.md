# HyprLarp
A collection of minimal hyprland dotfiles for daily use that actually performs and isn't just eye-candy.

The current desktop composes of hyprland, rofi and noctalia mainly.
Swaync, waybar config may be used if wanted.

> NOTE: noctalia settings.toml goes to  ~/.local/state/noctalia/settings.toml unlike other dotfiles which goto ~/.config/
